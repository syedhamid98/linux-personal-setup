## Fedora Workstation New Installation
1. Edit dnf.conf 
vi/etc/dnf/dnf.conf 
fastestmirror=True
max_parallel_downloads=10
deltarpm=True

2. Enable RPM Fusion (https://rpmfusion.org/Configuration)
sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm\
https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm

3. Setup flatpak (https://flatpak.org/setup/)
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

4. Update System and Reboot

## Networking
1. Disable IPv6 sysctl
vi /etc/sysctl.conf
net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
sysctl -p

2. Disable IPv6 grub
vi /etc/default/grub
GRUB_CMDLINE_LINUX='ipv6.disable=1' # add disable line only
grub2-mkconfig -o /boot/grub2/grub.cfg

3. Kernel parameters
sysctl -w net.ipv6.conf.all.disable_ipv6=1
sysctl -w net.ipv6.conf.default.disable_ipv6=1
sysctl -w net.ipv6.route.flush=1
